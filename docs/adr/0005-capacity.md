# ADR 0005：免费额度、容量与升级路线

- 状态：已接受
- 日期：2026-08-16

## 设计目标

- 对外目标 3,000 DAU，正常用户约 20 次动态请求/日。
- 首版合成验收数据：30,000 用户、约 80,000 条主题首帖和回复。
- 长期压缩图片 15,000–18,000 张，应用最多主动使用 8GB R2。

这些是工程目标，不是 Cloudflare 容量承诺或当前实测结果。

## 保护线

- Worker 70,000 次/日：降低轮询并告警。
- D1 读取 350 万行/日：暂停热门重算与高成本全文搜索。
- D1 300MB：告警；350MB 制定升级迁移；400MB 阻止非必要增长。
- R2 7GB：降低上传额度；8GB 停止新增上传。
- 邮件 80 封/日：告警；达到提供商免费上限时暂停新验证码。
- Queue 失败必须进入可观察失败记录或 DLQ。

主题列表使用 keyset cursor；热门分数由事件/Cron 预计算；阅读位置合并 upsert；浏览量近似批处理。不得为每次查看写主题行，也不得使用随数据增长的深 OFFSET。

达到任一资源 70% 或约 2,500 DAU 时评估 Workers Paid。优先扩展单库容量，不为了免费账户总存储提前引入跨库分片。
