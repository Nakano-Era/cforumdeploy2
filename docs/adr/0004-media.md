# ADR 0004：公开与私密媒体

- 状态：已接受，核心服务端生命周期已实现
- 日期：2026-08-16

当前已实现私有临时对象的额度预留、签名 PUT、R2 HEAD/头部 finalize 校验、帖子绑定、Public/Private 分流、统一受控读取、重新分级和定时孤儿回收。客户端压缩与编辑器上传体验仍属于后续实现范围。

## 决策

浏览器负责方向修正、去 EXIF/GPS、缩放、WebP/JPEG 编码及主图/缩略图生成。Worker 不执行重型转码。

生产上传使用 `aws4fetch` 生成短期 R2 S3 Presigned PUT URL。签名凭据只存在 Worker Secret，URL 绑定方法、对象键和 Content-Type。客户端声明不可信；finalize 必须用 R2 HEAD/读取头部重新校验字节数、magic bytes、MIME、像素尺寸、哈希、配额与对象所有者。

公开性不能只看等级数字。只有 Guest 通过完整 Topic 权限检查时，最终对象才复制到 Public R2 的不可变随机键，其余对象进入 Private R2。浏览器始终读取 `/api/media/:uploadId`，Worker 每次按当前帖子状态、主题等级与 Category ACL 重新授权；不可见、已删除或越权统一返回 404。公共响应只允许 60 秒 revalidate，并支持 ETag/304。

Public R2 只是内部存储层，不得绑定公开自定义域名或启用 `r2.dev`，否则会绕过 ACL 收紧后的 Worker 检查。Private R2 只对临时 Presigned PUT 配置精确来源的 CORS，不提供浏览器直读 URL。

绑定与重新分级采用“复制到本次尝试的随机目标键 → D1 条件切换 → 尽力删除旧对象”；竞态失败者会补偿删除自己的目标对象。任何中间失败都保持旧记录可读且 fail closed。审核批准后触发重新分级，读取路径在对象搬运前也会立即应用新权限。

默认不上传设备原图。`tmp/` 超过 24 小时后由每小时 Cron 分批清理；软删除媒体保留最多七天。R2 扫描游标持久化在内部站点设置中，单次任务有固定上限，可安全重试。

## 容量

应用软上限 7GB、硬上限 8GB。达到硬上限时停止新授权和 finalize，但已有内容继续可读。预留与 finalize 必须幂等，并在失败/过期时释放预留字节。

主题或板块权限变严时，Worker 读取会立即拒绝不再有权的请求，并可把对象重新复制到 Private R2。由于从不暴露 R2 对象地址，旧对象键不是公开 URL。
